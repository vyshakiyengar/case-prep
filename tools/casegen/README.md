# Case generator

Cases 16–102 in `src/content/cases.json` are generated by these scripts. Cases 1–15 are hand-written in `cases.json`; `fix_original15.py` holds the accuracy fixes applied to them.

Every number in a generated case is calculated in Python, and `assert` lines check that each claim in the text (which option wins, payback under target, and so on) is true for the numbers. If you change an input and a claim stops being true, the script stops.

## Files

- `b01.py`, `f01.py` … `f20.py`: the cases, about four per file. Each exports `CASES`.
- `lib.py`: case and question builders (`C`, `Q`, `T`), number formatting (`num`, `money`, `pct`, `signed`).
- `kit.py`: draws the charts as SVG with matplotlib (bar, line, waterfall).
- `show.py`: prints a module's cases as plain text for checking, e.g. `python3 show.py f19 Cinder`.
- `export.py`: rebuilds cases 16–102 into `src/content/cases.json` (keeping cases 1–15) and writes `caseCount.ts`.
- `fix_original15.py`: re-applies the fixes to cases 1–15. Safe to run more than once.

## Edit a case

1. Change the inputs or text in its module.
2. `python3 show.py <module> <title>` to read it back.
3. From this folder: `python3 export.py && python3 fix_original15.py && python3 index.py`
4. From the repo root: `npm run build`, then commit `src/content/cases.json`.

Needs Python 3 with matplotlib and numpy. Charts use IBM Plex Sans if its `.ttf` files are in `~/.fonts`; otherwise matplotlib's default font is used, which will change how the charts look.
